# Changelog

All notable changes to this package will be documented here.

## 1.0.0 - Unreleased

- Added the standalone `HandDrawnFont` runtime library.
- Added bundled handwritten alphabet, number, and punctuation artwork.
- Added animated and static text and glyph views.
- Added deterministic variation selection and replay triggers.
- Added custom typeface JSON loading, validation, and export.
- Added Reduce Motion, accessibility, and missing-character handling.
- Added the optional `HandDrawnFontDebug` inspection and glyph-authoring
  library.
- Added unit tests and human/LLM integration documentation.
